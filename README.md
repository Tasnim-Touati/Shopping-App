# Shopping-App

![React Native](https://img.shields.io/badge/React_Native-20232A?style=for-the-badge&logo=react)
![Expo](https://img.shields.io/badge/Expo-1B1F23?style=for-the-badge&logo=expo)

An e-commerce application built with **React Native** and **Expo**, featuring product browsing, detailed product views, and a shopping cart.

---

## 📦 Features
- Browse a list of products
- View detailed information for each product  
- Add products to a shopping cart 
- Clean, intuitive mobile interface  
- Easy to extend with more features (user login, payment integration)

---

## ⚡ Installation
1. Clone the repository:  
```bash
git clone https://github.com/Tasnim-Touati/Shopping-App.git
```
2. Navigate to the project folder:
```bash
cd Shopping-App
```

3. Install dependencies:
```bash
npm install
```
4. Start the Expo app:
```bash
npx expo start
```
---

## 📝 Usage

Browse products on the Home screen

Click a product to see details

Add products to the Cart
